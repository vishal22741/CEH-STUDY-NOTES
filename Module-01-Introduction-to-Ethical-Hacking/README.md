# Module 01 - Introduction to Ethical Hacking

## What is Hacking ?
   Hacking refers to as illegal activity that exploits system vulnerabilities and compromises security controls of system  
   to gain un-authorised access 
   
## What is Ethical Hacking ?
   Ethical Hacking is refers to as legal activity that tests vulnerabilities and compromises a system with permission 
   to safeguard the system or an organisation to protect it from un-intended or malicious behaviour
   
## Vulnerability ?
   It refers to as weakness or loophole in a sytem that leads to unexpected event which is compromising security of a system 
   
## Exploit ?
   Exploit defines that which is a software that is designed to take an advantage of an vulnerability 
   
## Payload ?
   Payload is a piece of code that is used as post exploitation to perform malicious activities in a compromised system
   
## ZeroDay Vulnerability ?
  A Zero Day vulnerability is a kind of vulnerability that is exploited before the software developer 
  patches it. Attacker takes advantage of this window before fix is available
  
## Why is it called Zero Day?
  Because developer has ZERO days to fix it before 
  it is already exploited

## Zero Day Attack Flow
1. Developer releases software
2. Unknown vulnerability exists
3. Attacker discovers it first
4. Attacker exploits it
5. Developer finds out
6. Patch released — but damage already done

## HackValue ?
Hack value is the level of achievement or reward an attacker obtains after successfully exploiting a vulnerability in a target system

## Types of Hackers ?
  - Black Hat:
      Individuals who computes his own skills to gain un-authorised access or to damage an organization in a illegal way
    
  - White Hat:
      Individuals who computes his own skills in a defensive perspective
    
  - Grey Hat:
      Individuals who works for both offensively and defensively
    
  - Hactivist:
      Hackers who promote a political agenda by hacking, especially by defacing or disabling websites
    
  - Suicide Hackers:
      An attacker who uses his own skills to reach the target or to compromise the target but
      do not care about being identified or facing legal consequences
    
  - Script Kiddies:
      An unskilled hacker who compromises the system by  running scripts,
       tools, and software developed by real hackers

 ## Why Ethical Hacking is Necessary
  Ethical Hacker needs to think like malicious Hacker. Ethical hacking is necessary to defend against 
  malicious hackers attempts, by anticipating methods they can use to break into a system
 - To fight against cyber crimes
 - To protect information from getting into wrong hands
 - To build a defensive mechanism that avoids hackers from penetrating
 - To test the organization’s infrastructure security

## Steps to Perform Ethical Hacking
  1.Reconnaissance:
           which refers to information gathering of an target 
  2.Scanning:
           which refers to finding out of an vulnerabilities using a gathered information 
  3.Gaining Access:
           Attacker gains an access to an target system by exploiting a vulnerabilites which they have gathered 
            from reconnaissance phase and scanning phase
  4.Maintaining Access:
           Attacker maintains an access by remains undetected and mainly here attacker gains admin level privileges by uploading trojans etc.. 
  5.Clearing Tracks:
           Which is an final phase here attackers hides or deletes all the evidence of their actions from the victim machine to escape from investigations
